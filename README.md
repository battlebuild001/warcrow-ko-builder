# 워크로우 한국어 아미 빌더

공개 주소: https://warcrow-ko-builder-draft.hebi-cogitox.chatgpt.site/

로그인 없이 사용하는 정적 웹 앱이다. Chrome에서 설치할 수 있으며, 편성과 플레이 세션은 현재 브라우저의 localStorage에 저장한다. `dist/`가 배포 디렉터리다. 로컬 실행은 `python -m http.server 8000 -d dist`로 한다.

## 편성과 플레이

6개 진영의 177개 편성 레코드와 162종의 카드를 제공한다. 한글·영문·한영 표시를 지원한다. 목록은 작은 모델 이미지가 있는 한 줄 형식이며 검색·정렬·수량 조작·저장·JSON 내보내기를 제공한다. 일반전/WTS, 점수 상한, AVB, 최고 지휘부 및 용병 제한을 검사한다.

상단의 **로스터 저장 / 불러오기**와 폴더 버튼으로 저장 목록을 관리한다. 이름이 없으면 자동으로 붙이며, 불러온 목록은 같은 ID로 업데이트한다. 진영·게임 방식·점수 상한·유닛 수량·지휘관·개체별 합류 배정을 함께 저장한다. 기존 저장 목록을 유지하고, 파일 백업과 JSON 파일 가져오기로 다른 기기에 옮길 수 있다. 삭제는 실행 취소할 수 있으며, 플레이 중 저장은 현재 게임의 편성 복사본을 사용한다.

플레이 시작은 모험 선택 창을 먼저 연다. 순찰은 1개를 직접 또는 랜덤으로 고르면 즉시 시작하고, 시나리오는 1개를 고른 다음 업적 1개까지 선택해야 시작한다. 선택 완료 전에는 게임을 만들지 않으며, 취소하면 현재 편성과 이전 게임이 유지된다. 시작 시점의 로스터 복사본과 모험을 함께 저장한다. 기존 게임으로 돌아가기는 모험 선택 없이 재개한다. 랜덤 선택은 게임 시작용 창에서 제공하고 시나리오 열람 화면에서는 제공하지 않는다.

플레이 화면에서는 유닛 탭 선택, 좌우 버튼, 스와이프 또는 방향키로 카드를 넘긴다. 검색 버튼으로 규칙 사전을 열고 한국어·영문 이름과 규칙 본문을 검색한다. 스탯·카드 안의 밑줄 키워드도 같은 규칙 설명을 연다. 카드의 키워드 버튼은 해당 유닛의 사용 시점·처리 방법과 실제 능력·스위치 조건을 별도 팝업에서 표시한다. 플레이 세션은 편성의 복사본을 사용하며 점수·피해·스트레스를 계산하거나 기록하지 않는다.

캐릭터 합류는 기본 룰북 73–81쪽에 따른다. 쉼표로 묶인 Join 조건은 모두, `|`로 나눈 그룹은 하나 이상 충족해야 한다. 유닛 개체별 캐릭터는 한 명이며 캐릭터끼리는 합류할 수 없다. 동일 유닛을 여러 개 편성하면 개체별로 배정한다. 수량 변경으로 사라진 개체의 배정은 정리하며, 배정은 편성 저장·내보내기·플레이 스냅샷에 포함된다.

합류 카드는 캐릭터의 합류용 프로필에서 절대값은 대체하고 `+`는 더한다. 별도 수정치는 각각 스트레스 1을 쓰는 독립 선택으로 유지한다. 합류용 능력·스위치와 예외적으로 유지되는 Permanent 능력을 표시하며, 일반 캐릭터 프로필을 중복 적용하지 않는다. 캐릭터는 병력 한 명으로 포함하지만 특성·키워드를 자동 공유하지 않는다. 장교/지원 구분도 표시한다. 플레이 화면은 합류와 해산만 기록한다. 합류할 때는 대상 유닛만 고르며, 해산은 바로 적용한다. 활성화 상태나 전장 조건을 입력·확인하는 절차와 잠금은 사용하지 않는다.

## 카드와 데이터

카드는 원본 이미지를 조각내거나 번역을 덮지 않고 HTML/CSS와 공식 Warcrow 기호 글꼴로 렌더링한다. `native-cards.json`의 원본 대조 프로필 162종, 전투 행 260개, `card-abilities.json`의 능력 467개, `card-effects.json`의 스위치 453개를 사용한다. 영문 원본 카드는 별도 참조 링크로 연다. `card-profiles.json`의 예전 OCR 위치 자료는 카드 렌더링에 쓰지 않는다.

공식 상세 카드가 없는 아마우리 보아소나드·루디빈 코르뱅·이스마일 디 에이스 필러·네아카일 오엔 피아라는 확인된 편성 정보만 표시한다. 합류용 수치를 확보하지 못한 경우 배정만 저장하며 미확인 보너스를 만들어 넣지 않는다. 모델 사진 134종과 공식 일러스트 28종은 `model-images.json`의 출처와 함께 제공한다.

## 룰북과 시나리오

`rules.html`은 사용자가 제공한 기본 룰북 1.6.1의 인쇄 2–120쪽을 순서대로 번역한 전문 리더다. 본문·목록·표·그림 안의 규칙 문구·부록 예시를 포함하며 원문 도해와 영문 텍스트를 함께 볼 수 있다. 장별 탐색, 쪽 바로가기, 전체 검색, 읽던 위치 복원, 인쇄/PDF 저장을 지원한다. 예시 카드의 수치는 해당 룰북의 출간 시점 값을 보존한다.

WTS 일반 규정은 공식 2026.11.03판 5–18쪽의 모든 운영 절차를 자세히 설명한다. `scenarios.html`과 플레이의 시나리오 창은 같은 판의 순찰 5개·시나리오 7개·업적 8개 및 공식 배치도 12개를 제공한다. 순찰은 독립 모험이며 일반 시나리오는 업적 하나와 조합한다. 시나리오 단독 화면과 플레이 팝업의 접을 수 있는 종류 안내에서 세 종류의 차이, MP·AP 역할과 VP 합산을 설명하며 WTS 10쪽으로 연결한다. 모험 선택은 플레이 세션에 저장한다. 언어판의 규정이 다르면 WTS의 규정에 따라 스페인어판을 적용하고 해당 항목에 출처와 차이를 표시한다.

- 기본 룰북: `rulebook-core-a.json` ~ `rulebook-core-d.json`
- WTS 운영 규정: `rulebook-wts.json`
- 원문/도해: `rulebook-source.json`, `rulebook-figures.json`, `rulebook-art/`
- 모험: `scenarios-data.json`, `scenarios-assets/`
- 합류 조건·장교/지원 유형: `join-metadata.json`
- 규칙 사전: `rules-glossary.json`의 149개 항목

서비스 워커는 앱의 핵심 파일, 룰북·모험 데이터와 도해를 캐시한다. 네트워크에 한 번 연결하여 설치를 마친 뒤에는 해당 자료를 오프라인에서도 읽을 수 있다.

## 팩션·로스터·운영 가이드

`strategy.html`에서 공통 편성 원칙과 여섯 팩션의 유닛 역할, 합류 조합, 배치·초중후반 운영, 상대 유형별 대응과 연습 과제를 읽는다. 한국어·영문 유닛 이름 및 본문을 검색하고, 유닛 링크로 실제 카드를 연다. 본문의 밑줄 키워드는 빌더와 같은 149개 규칙 사전 팝업을 열며, 사이언즈의 팅지 예외와 숫자가 붙은 배치·쇼브 등의 표현도 구분한다. 일반전 245–250점 연습 로스터 12개는 현재 프로필의 점수·AVB·지휘관·합류 조건을 검사했으며 JSON으로 내려받아 빌더에서 가져올 수 있다.

내용은 `strategy-common.json`과 `strategy-factions/`에 저장한다. 공식 규칙·프로필, 프로필을 해석한 운영 제안, 영상·전술 글의 의견을 구분하고 출처의 게시·확인 시점과 적용 한계를 표시한다. 대회 참고 자료는 WTS 시즌 2이며, 확인하지 못한 우승 명단·승률 통계·레딧 게시물은 근거로 사용하지 않는다. 연구 메모는 `research/`에 둔다.

공식 2026년 11월 3일 핫픽스의 레드 캡 분리와 수록 데이터 0.13.51의 차이를 가이드에 안내한다. 사이언즈 예시는 제거된 10개 프로필을 제외하며, 독립 레드 캡 팩션의 명단은 이 여섯 팩션 가이드에 포함하지 않는다.
