# 워크로우 아미 빌더

6개 진영의 177개 유닛 레코드를 사용하는 정적 웹 앱이다. 일반전과 WTS 시즌 2 편성, 250점 기준 점수 상한, AVB, High Command, 용병 최대 1개 및 시즌 2 출전 불가 유닛을 검사한다.

상단과 카드 창의 `한글 / English / 한·영` 버튼으로 표시 언어를 바꾼다. 한글은 카드 위에 번역을 표시하고, English는 원본 영문 카드 이미지를 표시한다. 한·영은 카드 위 한국어와 능력·전투 효과의 영문 원문을 함께 제공한다. 선택 언어는 브라우저에 저장되며 편성 수량·목록 입력은 언어 전환 시 유지된다.

`플레이 모드 · 카드 보기`를 누르면 선택한 유닛의 카드가 바로 표시된다. 지휘관 지정이나 점수 검사는 플레이 모드 진입을 막지 않는다. 유닛 종류마다 카드 한 장을 표시하며 수량은 선택 목록에 함께 표시한다. 좌우 버튼, 휴대폰 스와이프, 키보드 방향키로 카드를 넘기거나 목록에서 바로 선택할 수 있다. 마지막 카드에서 다음을 누르면 첫 카드로 돌아간다. 선택한 카드와 편성 복사본은 브라우저에 저장된다. 플레이 모드에는 점수·승점·라운드·피해·스트레스 계산 및 기록 기능이 없다.

`dist/`가 배포 파일이다. `app-data.json`은 `/workspace/warcrow-research`의 수집 자료에서 생성했다. 정식 서비스 전에는 Officer/Support 구분과 유닛 프로필을 CorvuSphere 최신 자료와 대조해야 한다.

`card-ko.json`은 162종의 한국어 유닛 이름과 확보한 카드 이미지 158종의 한국어 텍스트 초안을 담는다. 카드 텍스트는 OCR 및 자동 번역을 거쳤으므로 주사위 기호, 상태 효과, 수치의 원본 대조가 필요하다. 원본 카드 이미지가 제공되지 않는 4종은 편성 메타데이터만 한국어로 표시한다.

원본 카드 이미지가 있는 158종의 카드는 원본 프로필·주사위·전투 기호·강화 패널을 유지하고, 능력 467개와 전투 효과 449개를 높이가 자동으로 늘어나는 한국어 영역으로 표시한다. 문구를 숫자나 「능력 N」으로 바꾸지 않으며 전문을 카드 안에서 바로 읽을 수 있다. 각 효과의 발동 기호와 능력 종류 문양은 원본 이미지 조각으로 함께 표시한다. 한·영 모드에서는 해당 능력 아래 영문을 함께 표시하고, English 모드에서는 원본 카드 전체를 표시한다.

기호의 정확한 모양은 158종 원본 카드 이미지 안의 도식을 사용한다. `dist/icons.svg`의 벡터 기호는 원본 카드가 없는 경우의 대체 화면에 쓰인다. 원본 카드 이미지가 제공되지 않는 4종(`amaury_boissonade`, `ismail_the_eighth_pillar`, `ludivine_corbin`, `neakail_oen_fhiahra`)은 편성 메타데이터와 확보된 번역만 표시한다. 뒤의 두 캐릭터는 공식 사이트에 인물 초상만 있고 전체 카드 이미지는 없다.

`dist/card-profiles.json`은 카드별 기본 능력치, 전투 주사위와 강화 패널 경계·보너스 자료다. `dist/card-abilities.json`과 `dist/card-effects.json`은 원본의 능력·전투 효과 상자별 좌표, OCR 및 한국어 번역 초안이다. 생성 과정은 `/workspace/warcrow-research/extract_card_profiles.py`, `extract_enhancement_stats.py`, `extract_ability_boxes.py`, `translate_ability_boxes.py`, `extract_effect_boxes.py`, `translate_effect_boxes.py`에 있다. 공식 규칙용으로 확정하려면 각 카드의 모든 문구를 추가 대조해야 한다.

색상 테마는 프로젝트의 워크로우 지침을 따른다: 배경 `#16131C`, 표면 `#241F2E`, 주 강조 `#B6A0DE`, 보조 강조 `#94B9AC`. `dist/style.css`의 공통 변수에서 파생 색을 관리한다. 주사위의 빨강·노랑·주황·초록·파랑은 게임 정보이므로 색상 의미를 유지한다.

로컬에서 보려면 `python -m http.server 8000 -d dist`를 실행한다.

유닛 이미지 162종을 제공한다. 모델 사진 134종과 공식 유닛 일러스트 28종을 구분해서 표시하며, 이미지 창에서 원본 출처를 확인할 수 있다. 카드 능력 467개는 원본 이미지와 대조해 번역을 검토했고, 잘못 추출된 중복 전투 효과 영역을 제거했다. 기호는 종류를 구분한 텍스트(별·방패·느낌표·주사위 색상 등)로 함께 설명한다.

편성 화면은 모델 이미지 그리드와 이미지 진영 선택을 제공한다. PC에서는 편성표가 오른쪽에 고정되고, 모바일에서는 하단 편성·플레이 버튼과 키보드 포커스를 지원하는 편성표 시트를 사용한다. 이름·한국어 규칙·음차 능력명으로 검색할 수 있다. 유닛·진영·능력 고유명사는 음차하고, 규칙 설명은 자연스러운 한국어로 유지한다. `card-abilities.json`의 `titleKo`와 `rulesKo`가 표시 이름·본문의 기준이다.

카드의 밑줄 용어·효과 발동 기호·능력 문양을 누르면 공식 기본 룰북 1.6.1에 근거한 규칙 사전이 열린다. MOV/W/WP/MOR/AVB는 원본 이미지의 해당 칸 전체를 눌러 설명을 볼 수 있다. 규칙 사전 149개 항목은 적용 시점·조건·해제·예외·관련 규칙·인쇄 쪽수를 제공한다. 팅지 표는 해당 카드의 진영에 맞춰 일반 표 또는 사이언즈 전용 표를 먼저 표시한다. 표시 용어는 「팅지」로 통일하며 예전 명칭은 검색 별칭으로만 유지한다.
